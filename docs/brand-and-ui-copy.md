# TransformAI Brand and UI Copy

## Brand

**Name:** TransformAI  
**Tagline:** One source. Every message.  
**Personality:** composed, capable, precise, public-service ready.  
**Visual direction:** deep navy `#0B1F3A`, signal teal `#14B8A6`, warm highlight `#F59E0B`, cloud `#F8FAFC`, slate text `#1E293B`.

Use a simple code-native logo: a small teal source dot flowing through three navy destination bars, followed by the wordmark `TransformAI`. It remains crisp in the browser and avoids a late-stage image asset dependency.
