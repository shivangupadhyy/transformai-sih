# Demo Scenario — Phishing Defence Advisory

## Scenario

A fictional national cyber coordination centre has identified a phishing campaign impersonating its secure document-sharing service. A communications officer needs one source brief transformed into an executive briefing, a public-facing advisory, a professional LinkedIn update, and a video-production package.

Use [`sample-data/fictional-phishing-brief.md`](../sample-data/fictional-phishing-brief.md) for the live demo. It is invented solely for demonstration and contains no sensitive information.

## Demo script (about 90 seconds)

1. Sign in and show the **New transformation** dashboard.
2. Paste the brief, select all four outputs, and use the preset **Public-safety alert**.
3. Generate the project. Call out that all outputs come from the same source and settings.
4. Open the Executive Summary, then the Advisory. Point to source-grounded claims and the editable result.
5. Open LinkedIn Post to show channel-specific tone and the Video Package to show its storyboard, narration, subtitles, and visual guidance.
6. Open project history to prove outputs are saved, then copy or download the advisory.

## Required demo data

- Demo account: a new test user owned by the presenter.
- Project title: `Phishing Defence Advisory`.
- Output settings: audience `Government and critical-infrastructure stakeholders`; tone `Clear and authoritative`; objective `Inform and prompt action`; detail `Standard`; language `English`.
- Backup: a pre-generated version of the same project in history in case an upstream API is slow.
